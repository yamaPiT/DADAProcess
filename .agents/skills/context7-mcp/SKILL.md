# 外部調査スキル (Context7 MCP連携)

本スキルは、ローカル環境（PC内部）に存在しない最新の技術ドキュメントやAPI仕様を、外部から正確に取得するための手順書です。

## 実行手順 (Mechanical How)

1. **発動条件**:
   - コードの生成、環境のセットアップ、設定手順の確認時に「最新の公式情報が必要だ」とエージェントが判断した場合、自律的に本スキルを実行してください。
2. **調査の実行**:
   - context7 MCPサーバーを利用し、指定された技術の最新公式ドキュメントを検索・取得します。
3. **推測の排除**:
   - 取得した一次情報（事実）のみを抽出し、勝手な推測や古い学習知識を混ぜずに、思考を担当しているペルソナ（アーキテクトやプログラマー）へ情報を渡してください。
4. **出典の明記**:
   - 渡す情報には、取得元（ライブラリ名・バージョン・ドキュメントの該当箇所）を必ず添えてください。出典のない情報は、後から検証できません。

## 取得できなかった場合（上限と行き先）

- **試行の上限は3回まで**とします。検索語を変えて再試行してよいのは2回目・3回目までで、それ以上繰り返してはなりません。
- 3回で目的の情報が得られない場合は、**調査を打ち切り**、以下を呼び出し元のペルソナへ報告してください。
  - 何を調べようとしたか / 試した検索語 / 得られなかった事実
- そのうえで、**推測で埋めずにProduct Ownerへエスカレーション**し、参照すべき情報源の提示を仰いでください。
- MCPサーバーが未設定・接続不能な場合は、1回目の失敗で即座に打ち切り、「context7が利用できないため未調査である」事実を報告してください。

## 禁止事項

- **推測による代替の禁止**: 調査が失敗したことを隠し、学習知識や推測で埋めた内容を「調査結果」として渡してはなりません。
- **未調査の隠蔽の禁止**: 本スキルを実行していないのに「最新情報を確認した」と報告してはなりません。MCPサーバーが使えなかった場合は、その事実を明記します。
- **古い知識の混入の禁止**: 取得した一次情報と、自分の学習知識を混ぜて1つの記述にしてはなりません。両者は区別して伝えます。
- **バージョンの取り違えの禁止**: 対象プロジェクトが使用しているバージョンと異なるドキュメントを、断りなく適用してはなりません。バージョンが不明な場合は確認します。
- **無制限な再試行の禁止**: 上限3回を超えて検索を繰り返してはなりません（時間とトークンを浪費するため）。
- **越権の禁止**: 本スキルの役割は情報の取得と受け渡しのみです。取得した情報をもとに設計判断や実装を行ってはなりません（それは `architect` や `programmer` の役割です）。
