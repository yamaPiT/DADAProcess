# 会議議事録

> 本ひな形は UNIT-002（議事録ひな形知識）として定義された議事録の標準フォーマットです。
> 以下の6つの必須見出し、日付書式、およびTODO表の3列ヘッダー構造を厳格に維持してください。

## 1. 会議概要
- **日時**: YYYY-MM-DD HH:MM-HH:MM（例: 2026-09-04 10:00-11:00）※日付書式は必ず YYYY-MM-DD 形式とする
- **場所**: 会議場所または「オンライン」
- **出席者**: 出席者氏名（役職・役割）
- **目的**: 会議の目的・ゴール

## 2. 決定事項
- 会議で正式に合意された決定事項を箇条書きで記載する。
- （合意された決定事項が存在しない場合は「決定事項なし」または「なし」と明記する）

## 3. 討議内容
### 議題1: [議題名]
- **論点**: 議論された背景・課題
- **発言要約**: 主要な意見・発言内容の要約
- **結論 / 状況**: 議論の結果または次回への持ち越し事項

### 議題2: [議題名]
- **論点**: 
- **発言要約**: 
- **結論 / 状況**: 

## 4. TODO一覧
| タスク内容 | 担当者 | 期限 |
| :--- | :--- | :--- |
| [具体的なアクションアイテム] | [氏名 / 未定] | [YYYY-MM-DD / 未定] |

※担当者または期限が会議メモから特定できない項目は、空欄にせず必ず「未定」と記載する。
※決定事項そのものはTODO一覧に含めず、具体的な実行課題（アクションアイテム）のみを記載する。

## 5. 次回議題
- 次回会議で検討・報告が予定されている事項を箇条書きで記載する。
- （次回議題が特に指定されていない場合は「次回開催時に別途調整」または「なし」と明記する）

---

### ひな形運用上の禁止事項
1. **必須見出しの改変禁止**: `# 会議議事録`、`## 1. 会議概要`、`## 2. 決定事項`、`## 3. 討議内容`、`## 4. TODO一覧`、`## 5. 次回議題` の見出しテキストおよび階層を変更・省略してはならない。
2. **日付書式の改変禁止**: 日付表記において、スラッシュ区切り（例: `2026/09/04`）や日本語年月日表記（例: `2026年9月4日`）を使用してはならない。必ずハイフン区切り（`YYYY-MM-DD`）とする。
3. **架空情報の創作禁止**: 会議メモに存在しない人物名、発言、決定事項、日付を推測・創作して埋め込んではならない。
