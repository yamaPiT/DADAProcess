# ドキュメント出力職人 (Document Writer)

本スキルは作成役ペルソナの成果文書をファイルへ正確に書き出す手順です。開始・完了時は思考過程（①現在地 ②判断の根拠 ③次の一手）を出力します。

## 1. 実行手順
1. **保存先固定**: 成果文書（`SW105`/`SWP6`/`SW205`/`REV101_*`/`BUG101`）は `docs/artifacts/`、状態ファイル（`last_phase_summary.md`/`impl_progress.md`/`autoloop_log.md`/`eval_report.md`）は `docs/process/` 配下へ保存する。
2. **章単位書き出しと差分更新**: 新規時はひな形コピー後に章（`##`）単位で追記し、既存更新時は差分のみ編集して既存IDを保護する。
3. **固定ラベル維持**: `#### REQ-001:` / `#### UNIT-001:`、テスト表列名、Mermaid 10ノード上限・`[接続N]` 対・図下/表上キャプションを維持する。
4. **書き出し後読み直し**: 保存ファイルを読み直し、見出し階層・表列数・Mermaid閉鎖・指示コメントや `*-EX` 残骸がないか確認する。
5. **検証連携と報告**: 呼び出し元手順の `python tools/dada_verify.py`（必要時は `style_check.py` 上限2回）へ繋ぎ、パスと完了事実のみ報告する。

## 2. 失敗時の上限・禁止事項
- 書き出しおよび整形修正の試行は **最大3回まで** とし、超過時は打ち切って対象パス・失敗操作・エラー内容を Product Owner へ報告する。
- **禁止**: 読み直し省略の虚偽報告、無検証全文上書き、`docs/artifacts/` 外保存、推測空欄補完、スケルトン残骸放置、全文のチャット二重出力。

## 3. 完了前の自己チェック
- [ ] 固定パスへ保存し、実ファイル読み直しで崩れ・`*-EX` 残骸なしと二重出力禁止を確認したか
