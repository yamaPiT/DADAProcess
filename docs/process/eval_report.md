## 判定の規則

- 1回の試行の合格とは、**必須要素をすべて満たし、禁止要素を1つも含まないこと**である（部分点で合格としない）。
- 合格率が閾値以上のときのみ、その評価IDを「合格」とする。
- **試行回数を減らして合格させることを禁止する。** SWP6で定義された回数（10回）を必ず実施する。
- **評価セット・必須要素・禁止要素・閾値を緩めて合格させることを禁止する**（テストの改ざんに相当する）。
