# (REV101) テスト仕様・報告レビュー記録表

【運用ルール】
1. **Phase 2（計画）**では、総合テスト仕様書・報告書（SWP6）の1〜4章を対象にする。
2. **Phase 4（報告書）**では、SWP6の5〜6章（実施結果と総合判定）を対象にする。計画（1〜4章）の再レビューはしない。

4. **AIエージェント**は、この記録表を読み込んで指摘箇所を修正し、「対応結果・修正内容」を追記して、ステータスを「解決済」に変更します。
