# (REV101) アーキテクチャ設計レビュー記録表

【運用ルール】
1. **人間（Product Owner）**または**レビュアーエージェント**が、アーキテクチャ設計書（`SW205`）をレビューし、指摘事項を「指摘内容」列に記入します。指摘分類は **`[ASDoQ:特性-副特性]`** 形式で統一して記述します。
