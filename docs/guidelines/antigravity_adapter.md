# Antigravity 最適化アダプター（ポータブルコア分離層）

本指針は、Antigravity App（CLI含む）固有機能（`invoke_subagent`、`run_workflow`、明示指示時の `/swarm`、モデル配分）をポータブルコア層（`.agents/AGENTS.md`・各スキル）から分離して提供する拡張層である。コア層は本ファイルへ必須依存しない。

## 1. 思考過程の出力（必須）
アダプター適用可否の判定・実行時は、開始時と完了時に以下3項目を必ず出力する。
- **①現在地**: 検出した実行環境・利用可能ツール（`invoke_subagent` / `run_workflow` / `/swarm` の有無）と現在工程
- **②判断の根拠**: 環境判定に基づくモデル使い分け・並列実行・フォールバックの選定理由
- **③次の一手**: 次に実行する委譲・並列実行・または順次切替アクション
- DADA工程の計画提示時は末尾に `[DADA | Phase N: フェーズ名 | ...]` 1行を付与する。

## 2. モデル役割分担基準（Plan / Execute・軽量モデル活用）
利用環境がモデル選択に対応する場合、推論負荷に応じて使い分ける。**特定モデル世代名や固有モデルIDの固定記述は禁止する。**

| 役割カテゴリ | 割り当て基準 | 主な対象作業 |
| :--- | :--- | :--- |
| **Plan / 高推論モデル**（上位推論モデル） | 曖昧性判断、構造設計、トレードオフ比較、反証レビュー | Phase 0判定、SW105/SW205設計、反証レビュー、LLM-as-judge採点、難航バグ分析 |
| **Execute / 軽量モデル**（高速・低コストモデル） | 仕様確定後の定型実装、探索、単体テスト、反復評価試行 | コード探索、独立ユニット実装・単体テスト、評価セット（`EV-001`〜）のN回独立試行 |

- `invoke_subagent` 等では探索・定型処理・N回試行へ軽量モデル（高速プロファイル等）を割り当て、コンテキスト消費とコストを抑える。設計決定とレビュー本体には上位推論モデル（または `inherit`）を用いる。

## 3. 並列実行方針（`run_workflow`・独立サブエージェント・`/swarm`）
1. **独立ユニット・N回試行の並列化**: 相互依存のない複数 `UNIT` 実装（Phase 4）や `EV-ID` のN回独立試行は、`run_workflow` または並列 `invoke_subagent` で実行する。ワーカーには「担当ID・参照文書パス・出力先パス」のみ渡し、会話履歴要約は渡さない。
2. **`/swarm`（明示指示時のみ）**: Product Owner が「`/swarm` で並列に」等と**明示指示した場合のみ** `swarm` を適用する。**明示指示なしの無断 `/swarm` 起動は禁止する。**

## 4. 非 Antigravity 環境でのフォールバック手順
`invoke_subagent`、`run_workflow`、`/swarm` が不在の環境（Antigravity IDE、Claude Code 互換環境、Cursor、Codex、GitHub Copilot 等）では**エラー停止せず以下へ切り替える**。

| 不在のツール | フォールバック動作 |
| :--- | :--- |
| `run_workflow` / `/swarm` 不在 | 並列指示でもエラー終了せず、**順次実行**または**該当環境の標準サブエージェント方式**へ切り替える |
| `invoke_subagent` も不在 | 承認ゲート型は `context-reset` **方式B（新規チャット依頼）**、自律型は **方式C（論理リセット＋順次実行）** へ切り替える |

切替時は思考過程「①現在地」に非対応ツールの不在を宣言し、代替実行方針を報告して継続する。

## 5. 禁止事項
- 明示指示なき無断 `/swarm` 起動、特定モデル世代名・モデル名の固定記述。
- ポータブルコア層への Antigravity 固有ツール必須依存の混入。
- 非対応環境での未定義コマンド強制やエラー停止。
